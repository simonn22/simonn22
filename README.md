### Who am I? 
I'm an IT student, currently working on becoming a Network and System Administrator (ASIR).

**🖥️ What I do:**
* **SysAdmin & Self-Hosting:** I manage a home server ecosystem using Docker and Nginx reverse proxying. My lab includes media automation (Jellyfin, Sonarr, Radarr), remote desktop environments via Apache Guacamole and PostgreSQL, and network-wide ad blocking with Pi-hole on a Raspberry Pi.
* **Linux Enthusiast:** I am a daily Linux user. I run a dual-boot setup with Fedora KDE as my daily driver, alongside Debian and Ubuntu Server for my self-hosted services.
* **Tinkerer & Maker:** I love repurposing tech. Recent projects include building a custom e-ink dashboard using a modded Kindle with MagicMirror, and flashing custom ROMs like LineageOS to keep older Android hardware alive.
* **Scripting & Gaming:** I write Python automation scripts for logic games, manage and optimize custom Minecraft Fabric servers, and game on Linux using Proton.
* **Physical Media & Ownership:** I am a strong advocate for physical media and the consumer's right to truly own the products they pay for—a philosophy that extends from self-hosting my own data to spinning vinyl records on my turntable.

**🛠️ Tech Stack & Tools:**
* **OS:** Linux (Fedora, Debian, Ubuntu), Windows 11, ChromeOS
* **Infrastructure:** Docker, Nginx, PostgreSQL, Pi-hole
* **Languages:** Python, Bash, SQL
